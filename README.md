
# AI Tech Stack Recommender

## Description
An AI-based career recommendation system that suggests
the most suitable technical job roles based on user skills.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

## Features
- User skill input
- TF-IDF feature extraction
- Cosine similarity calculation
- Job role ranking
- Top 3 career recommendations

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   python recommender.py

## Algorithm
1. Input user skills
2. Apply TF-IDF
3. Calculate cosine similarity
4. Sort similarity scores
5. Display Top 3 recommendations
